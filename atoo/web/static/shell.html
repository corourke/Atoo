Input list

                CSV · input.csv · in the bundle
                  
                    
                    
                      One row per physical input, which is why a name lives here and
                      not on a strip: apply writes the name, colour and icon to the
                      socket, and the strip inherits them. Editable rows only — no
                      plan columns. Save writes the bundle's input.csv, changing only
                      the rows you changed; the plan then reads Stale until it is rebuilt.
                      Step 04 shows these same rows beside the plan: an edit made there is
                      an edit made here, unsaved until Save.
                      Order is the band's own number for each input; it does
                      not set the desk channel. Skip keeps a row in the file
                      and leaves it out of the next build. Drag a row by its handle, or move
                      it with ▲ ▼ or Alt+↑/↓; + inserts
                      a blank row below.

          Change
          
              
          
                
                
                  
                  
                    For the setup window: after the build, before doors, not mid-show. Save a console snapshot once the board is patched, and the worst a bad change can cost is a reload. A change starts from the plan this desk's newest write left on it (or plan.json if this bundle has not written to it); the review says which.                                     This is the Demo show
                                    
    
                                    It's a packaged show on a simulated WING Compact, so you can look at Build, Apply and
      Watch without a console.
                                    
    
                                      
      
                                    • Works: reading the show's files and plan, previewing a Full build
        against the simulated desk, previewing a typed Patch (when a model is set up), and
        watching the desk.
                                      • 
      
                                    • Switched off: saving changes, building, writing to a console, and
        Undo.
                                      • 
    
                                    
    
                                    To work on your own show, choose a console address in the bar, or open
      or create a show.
                                    
    
                                    
  
                                    
  
                                    
    
                                    Pre-flight verify
                                    
    
                                    Before anything touches the desk, Atoo checks the plan against the console it's
      going to: every socket exists, every stereo pair can be formed, and every value is within
      the console's range.
                                    
    
                                      
      
                                    • An error is a setting that can't work on this desk. It stops the
        write until it's fixed.
                                      • 
      
                                    • A warning or a note is listed in Findings and doesn't stop
        anything.
                                      • 
    
                                    
    
                                    It runs again whenever you come back to Apply, or press Re-check. You
      can skip it under Options, for example to write a plan you've already checked against this
      desk.

# Atoo

Patches a complete show on a Behringer WING from your input list and
conventions, audits it for correctness, and watches pre-show for routing
errors.

*Atoo is said "A-two": your A2, the second engineer at the desk.*

## Status

**Not released yet.** The code arrives here once it has passed its last
runs on a real WING Compact. Until then this repository holds only the
licence and this page.

A build needs your own AI API key: Atoo is built and tested on Claude.
The model builds the show plan, before the show; local code applies it
to the desk, with every write logged and undoable.

# Touringband notes

## Channels

- Vocals get their high-pass at **100Hz** tonight, not the usual 120Hz.
- Start all DI channels muted and set input gain to 15dB.

## Busses

- All monitor mixes are going to route to AES50-A outputs.
- Add monitor mixes MON5 and MON6 for IEM mixes in stereo.
- Start all monitor bus faders at off.

## Watch

- Alert if any vocals-category channel is muted.
- Alert if the Main fader moves below -10dB.
- Alert if any mix bus or FX bus fader is more than +/- 5dB
- Alert if any monitor bus fader comes up off the floor before soundcheck.
